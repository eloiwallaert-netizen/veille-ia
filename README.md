# veille-ia

Site de veille IA et de formations, catégorisé par métier (Chief of Staff, Sales, Customer Success, Product, Ingénieur/Data, Marketing, RevOps, People, Finance, Direction), pensé pour des nouveaux arrivants dans le monde de l'IA.

## Structure

- `index.html` : page du site, autonome (pas de build requis)
- `support.js` : runtime nécessaire au rendu de la page

## Déploiement

Site statique. Aucune commande de build : servir `index.html` tel quel (Netlify, Vercel, GitHub Pages...).
